# Atividades de Python 🐍

Repositório dedicado aos exercícios práticos e fundamentos da linguagem Python.

---

## 📁 Estrutura dos Arquivos

| Arquivo | Descrição / Objetivo | Conceitos Praticados |
| :--- | :--- | :--- |
| [`tipos-de-dados.py`](tipos-de-dados.py) | Apresentação dos tipos embutidos em Python com exemplo de filme. | Tipagem dinâmica, `str`, `int`, `float`, `bool`, `list`, função `type()`. |
| [`concatenacao.py`](concatenacao.py) | Exibição de textos combinados no console. | Múltiplos argumentos no `print()`, formatação e saída de dados. |
| [`input.py`](input.py) | Entrada interativa de dados via terminal e conversão. | Função `input()`, conversão de tipos (*type casting*) com `int()` e `float()`. |

---

## 🚀 Como Executar

No terminal, execute qualquer um dos scripts com:

```bash
python3 tipos-de-dados.py
python3 concatenacao.py
python3 input.py
```
